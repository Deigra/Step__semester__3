# Step Semester 3 - Data Structures Practice

Java solutions for the Category B Data Structures practice set (Arrays, Hashing, Two Pointers, Sliding Window, Binary Search).

## Structure

```
src/main/java/DataStructuresPractice/
├── ClassProblems/
│   ├── LibraryCatalogLookup.java
│   ├── WarehouseGridSummary.java
│   ├── PairWithTargetSum.java
│   └── MaxContainerArea.java
└── Assigement/
    ├── ClassTopperFinder.java
    ├── MergeTokens.java
    ├── MostPopularOrder.java
    ├── HotWeatherAlerts.java
    └── TicketPriceSlot.java
```

## Problems and Complexity

| Problem | Technique | Time | Space |
|---|---|---|---|
| Library Catalog Lookup | Binary search | O(log n) | O(1) |
| Warehouse Grid Summary | 2D traversal | O(m * n) | O(1) |
| Pair With Target Sum | Hash set | O(n) | O(n) |
| Max Container Area | Two pointers | O(n) | O(1) |
| Class Topper Finder | Nested loops | O(m * n) | O(1) |
| Merge Tokens | Two pointers | O(m + n) | O(m + n) |
| Most Popular Order | Hash map | O(n) | O(k) |
| Hot Weather Alerts | Sliding window | O(n) | O(1) |
| Ticket Price Slot | Binary search | O(log n) | O(1) |

## How to Run

1. Open the project in IntelliJ IDEA (JDK 17 or higher).
2. Open any file and click the green run button next to `main`.
